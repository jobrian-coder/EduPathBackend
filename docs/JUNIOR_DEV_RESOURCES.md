## Recommended Learning Order

### Week 1: React & TypeScript Fundamentals
1. React Docs - "Thinking in React" (4 hours)
2. TypeScript Handbook - Basic Types (3 hours)
3. Build a simple counter app with TypeScript

### Week 2: State Management & Data Fetching
1. React Query Tutorial (3 hours)
2. React Router v6 Tutorial (2 hours)
3. Build a todo app with React Query

### Week 3: AI/ML Concepts (EduPath Specific)
1. Vector Databases Explained video (30 min)
2. RAG Architecture article (1 hour)
3. Groq API Quickstart (1 hour)
4. ChromaDB Getting Started (2 hours)

### Week 4: Full-Stack Integration
1. DRF Tutorial (4 hours)
2. Build a simple API + Frontend integration
3. Review the EduPath codebase

## Study Plan Suggestion

### Daily Routine (2-3 hours/day)

**Morning (1 hour): Theory**
- Watch one YouTube video or read docs
- Take notes on key concepts

**Afternoon (1-2 hours): Practice**
- Code along with tutorial
- Build a small feature
- Debug and refactor

**Evening (30 min): Review**
- Review what you learned
- Write down questions
- Plan tomorrow's focus

---

**Remember**: The goal isn't to master everything at once. Focus on understanding the **concepts** behind what we built in EduPath, then practice with small projects.

**Key Advice**: 
- Build things. Don't just watch.
- Break the code on purpose to understand how it works.
- Read error messages carefully.
- Ask questions early.
